# Training Pathways Block

This free learner companion block displays assigned training pathways and
provides a convenient dashboard entry point to the learner's program progress.

## Features

- Show the current learner's assigned pathways.
- Present program progress using the parent plugin's records.
- Link learners to their pathway details.

## Requirements

- A compatible Training Pathways release, as declared in version.php.
- Moodle 4.4 or later within the declared supported range.
- A pathway assigned to the learner in the parent plugin.

## Installation

1. Install or update Training Pathways first.
2. Install block_trainingpathways in blocks/trainingpathways.
3. Complete Moodle's administrator upgrade screen.
4. Add the block to learner dashboards.

## Usage

Managers create and assign programs in Training Pathways. Learners use this
block to find those assignments and open their details. Course completion and
sign-off rules are evaluated by the parent plugin; the block does not grant
course access or certify completion by itself.

## Pricing

This companion block is free. The parent plugin has its own acquisition price.
